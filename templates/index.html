How It Works

Mode 1: Download CSVs

Generates Tabbycat-compatible CSV files that you manually import using:

  • Simple Importer: Copy-paste into Tabbycat's web interface
  • importtournament command: Run via SSH on your Tabbycat server

Mode 2: Direct API Import

Connects directly to your Tabbycat instance via REST API and creates:

  • Institutions first, then Teams (with nested Speakers), then Adjudicators
  • Requires API token from your Tabbycat account
  • Works with Calico, Heroku, Render, or self-hosted Tabbycat
